# MotoBridge Governance Portal

Reference web tooling to validate app specs against OEM profiles.

## What it does
- Accepts app metadata and OEM profile metadata (JSON or simple YAML).
- Validates against MotoBridge v1.0 OEM safety contracts.
- Produces one of three outputs: SAFE / RESTRICTED / REJECTED.

## What it does NOT do
- No APK uploads or installs.
- No marketplace or ranking.
- No OEM certification or legal approval.

## Run locally
Open `index.html` in a browser. The portal is static and has no backend.
